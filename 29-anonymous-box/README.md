# 匿名信箱 Bot

NGL 式匿名留言箱：箱主分享专属链接，访客留言被匿名转发，箱主回复即可匿名回信，双向都不露身份。

## 部署要点
同单体三步部署，变量：BOT_TOKEN*、BOT_USERNAME*（Bot 用户名，不带 @，拼链接用）、WEBHOOK_SECRET ＋ 必须绑定 KV 变量名 BOT_KV。

## 玩法
- 箱主：/mybox 拿到 https://t.me/<Bot>?start=box_<自己ID> 链接，发到频道/主页
- 访客：点链接后直接给 Bot 发消息（文字/图片/文件都行），Bot 用 copyMessage 复制投递——不带转发标记、不带发送者信息
- 箱主：回复收到的那条留言，Bot 按 KV 路由表（msgmap）匿名转回访客；访客再回复同理，来回聊都行
- 访客 /stop 结束当前会话

## 隐私与边界
- 访客 ID 只存在 Bot 自己的 KV 路由表里用于回信，箱主在 Telegram 界面上看不到。
- 箱主没法主动给访客发消息（只能回复），访客关掉会话后新消息投不出去。
- 匿名留言可能有骚扰内容：Bot 不做内容过滤，箱主可直接不理会或在 BotFather 拉黑 Bot 侧无法处理；收到骚扰时建议截图留证、向 Telegram 举报原账号（通过留言内容本身判断）。
