# 星座运势 / 塔罗 Bot

每日星座运势 + 塔罗三张牌，零必需外部 API，开箱即玩。

## 部署要点
同单体三步部署，变量：BOT_TOKEN*、WEBHOOK_SECRET、ASTRO_API_URL（选填）。KV 选绑 BOT_KV：绑了能记住星座偏好（astro:pref:）并支持塔罗跨步抽牌（tarot: 会话）；不绑 KV 时 /astro 现选现看可用，/tarot 会提示需绑 KV。

## 玩法说明
- /astro：出 12 星座按钮，点选出今日运势并记住偏好；下次 /astro 直接出。也可 /astro 白羊座 直接指定。
- 运势怎么来的：默认**本地种子文案库**——用「星座+北京日期」做确定性种子生成整体星级、感情/事业/财运分项、幸运数字与幸运色，同人同天结果稳定、零点自动换新，和真正的每日运势产品一个手感。文案池在 worker.js 的 POOL，想扩充往里加句子。
- 配了 `ASTRO_API_URL`（通用口径：GET ?sign=<星座key>&date=<日期>，期望 JSON 含 text/fortune/content）就优先用外部运势并标注来源口径，拉不到自动回落本地，不会开天窗。
- /tarot：点按钮逐张抽牌，原地编辑消息分步揭示「过去/现在/未来」，三张不重复、正逆位随机，抽满给综合解读，可「再抽一组」。牌库是本地 22 张大阿卡纳（worker.js 的 ARCANA，含正/逆位解读）。

## 娱乐声明（必留，别删）
运势与塔罗均为**娱乐内容，非科学预测**。/start、每条运势、塔罗综合解读末尾都带这句声明（代码里的 DISCLAIMER 常量），删了它这模板就不完整——占星品类在各目录站都要求明确娱乐定位，拿它做付费「改运」更是红线。

## 注意事项
- 日期口径是北京时间（bjDate），半夜不换运势是因为还没到北京零点，不是 Bug。
- 塔罗会话 1 小时过期（KV TTL），抽一半放凉了要重开一局。
