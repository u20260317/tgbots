# 活动抽奖 Bot

频道/群运营的活动抽奖：帖子带参与按钮、可验订阅条件、到时自动开奖公布。是 13 号抽奖（Bot 内签到积分场景）的活动版补全，对应 TgGrow / TGPicker 那类工具。

## 部署要点
同单体三步部署，变量：BOT_TOKEN*、WEBHOOK_SECRET、ADMIN_ID（平台管理员）、GIVEAWAY_CHATS（参与前必须订阅的频道/群，逗号分隔，留空=无条件）＋ 必须绑定 KV 变量名 BOT_KV。
⚠️ Bot 必须是活动聊天和 GIVEAWAY_CHATS 频道的管理员（否则编辑帖子/查订阅状态都会失败）。
自动开奖需 Cron Trigger `*/1 * * * *`；不加 Cron 就用 /drawgw 手动开奖。

## 玩法说明
- 发起（群管理员或 ADMIN_ID）：/giveaway 奖品|中奖人数|开奖时间，例：`/giveaway 会员月卡|3|2小时后`；时间可写 N分钟后/N小时后/N天后/今天或明天 HH:MM。
- 参与：成员点帖子「🎁 参与」按钮；配了 GIVEAWAY_CHATS 时当场核验订阅，没关注会弹窗提示、关注后重点即可；重复点会去重。
- 开奖：到时 Cron 自动开（或发起人/管理员 /drawgw <ID> 手动开），crypto 随机抽取，编辑原帖公布名单，并逐个私信中奖者；没私聊过 Bot 的人私信不到，帖子里的公示名单就是凭证。
- /gwlist 看本聊天进行中的抽奖。

## 评论参与模式（默认关，限制先说清）
代码 CONFIG.COMMENT_MODE 改 true 后：在频道**关联讨论组**里回复那条被自动转发的抽奖帖，即登记参与。限制：依赖讨论组关联与转发标记完整，用户隐私设置、频道未开讨论组等都会漏登记——正式活动请以按钮参与为准，评论模式只作补充，别拿它做唯一名单来源。

## 注意事项
- 参与名单存在 gw:<抽奖ID> 单条记录里（与 13 同模式）：千人级活动没问题；万人级大活动 KV 单值与并发写会成瓶颈，请分场次或换 D1。
- 开奖随机源是 crypto.getRandomValues 洗牌，不是 Math.random，结果先落盘再公布，可复核。
- 订阅核验要求 Bot 在目标频道是管理员；目标是公开频道时用 @用户名、私有频道用数字 ID 并配邀请链接在帖文里说明。
