# 个人提醒 / 待办 Bot

每个用户自己的提醒与待办：自然语言时间建提醒，到点推送；待办清单按钮勾选。与 21（管理员对频道排播）是完全不同的东西。

## 部署要点
同单体三步部署，变量：BOT_TOKEN*、WEBHOOK_SECRET、TZ_OFFSET（默认 8=北京）＋ 必须绑定 KV 变量名 BOT_KV。
⚠️ **必须给 Worker 加 Cron Trigger `*/1 * * * *`**（Cloudflare 面板 Settings → Triggers），否则提醒只存不响。另注意免费版 Cron 与 KV 读额度：每分钟扫一遍 rem: 前缀，用户量大时把 Cron 改成 `*/5` 并接受 5 分钟粒度，或按模块 27 的思路分片。

## 玩法说明
- /remind <时间> <内容>，时间写法（启发式解析，认不出会让你重发，绝不瞎猜）：
  - `10分钟后 交房租`、`2小时后 开会`、`3天后 续费`（默认上午 9 点）
  - `明天 9:30 开会`、`今天 21:00 抢票`（今天的点已过自动顺延明天）
  - `每天 8:00 吃药`（周期）、`每周一 9:00 写周报`（周期）
- /remlist 看全部提醒（每条带删除按钮）；一次性提醒响完自删，周期提醒自动顺延。
- /todo <内容> 加待办，/todos 看清单：按钮 ✅完成/↩️取消完成、🗑 删除。
- 提醒与待办都按用户隔离（rem:<用户ID>:<提醒ID>、todo:<用户ID>），群里也能用，响铃发回原聊天。

## 注意事项
- 时间按 TZ_OFFSET 的当地墙上时间算，跨时区用户让管理员改变量（全 Bot 统一一个时区，v1 不做 per-user 时区）。
- Cron 扫描单轮最多 1000 条（KV list 上限），个人/小圈子足够；错过触发窗口的提醒会在下一轮补发（消息里标注原定时间）。
