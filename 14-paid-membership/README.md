# 付费会员 Bot

卖付费群/频道会员：选套餐 → 按你的收款说明付款 → 管理员按钮确认 → Bot 自动发一次性邀请链接并记录到期，Cron 每日巡检到期自动踢人。

## 部署要点
1. 同单体三步部署，变量：BOT_TOKEN*、ADMIN_ID*、TARGET_CHAT_ID*、PAYMENT_INFO*（收款地址/说明原文）、WEBHOOK_SECRET ＋ 必须绑定 KV 变量名 BOT_KV。套餐改 worker.js 顶部 PLANS（名称/价格/天数）。
2. **加一条每日 Cron**：Worker → Triggers → Cron Triggers → `15 3 * * *`，到期巡检靠它；不加则只能管理员手动 /sweep 或 /kick。
3. Bot 是目标群/频道管理员，需邀请成员 + 封禁成员权限（踢人用）。

## 说明（重要，先看）
- 这是**人工收款确认**模式：钱走你自己的渠道，Bot 只管订单、发链接、记到期，不经手资金。谨防假付款：管理员确认前务必核对到账。
- 会员有效期从管理员点「通过」那刻起算，邀请链接 48 小时内有效且限 1 人；用户没及时点链接进群，到期照样按记录踢（记录在，人不在群则踢人接口无害失败）。
- 续费自动顺延：老会员未到期时续费，新天数从原到期日往后加。
- 想要全自动（支付回调自动开通）：把「支付确认流」模块的管理员确认换成你的支付平台 webhook 调 /push 式接口即可，模块已按积木标注拆好。
