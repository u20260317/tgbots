# 公版书库 Bot

检索 Project Gutenberg 的公版书目，点按钮就把电子书发进聊天。数据源是 Gutendex 免费 API（免 key、免注册，开箱真跑）。

## 部署要点
单体三步部署，变量：BOT_TOKEN*、ADMIN_ID（看 /gbstats）、WEBHOOK_SECRET ＋ 必须绑定 KV 变量名 BOT_KV（存书架）。无需任何第三方 Key。

## 玩法说明
- /search <书名或作者>：调 `GET gutendex.com/books?search=`，前 5 本逐本发书籍卡（书名/作者/语言/下载量），卡上按钮选 EPUB / PDF / TXT 格式 + ⭐ 加入书架。
- 取文件：先按 Gutendex 书目 ID 重新拉详情拿最新直链，HEAD 探大小——≤50MB 走 sendDocument 让 Telegram 直接抓取回传（TG 拉不动自动兜底发直链），>50MB 直接回直链并说明 Bot API 上限。
- /random：Gutendex 没有随机端点，模板用「随机翻一页目录取第一本」实现等效随机推荐。
- /shelf：个人书架存 `shelf:<uid>`（只存 id+书名，取书时现查目录，链接永不过期），卡上可取书/移除。

## 版权边界（重要，与盗版书库的界线）
- Project Gutenberg 只收录**在美国版权法下已进入公有领域**的作品（外加少量获明确授权的作品），全站有专职版权核查流程。本 Bot 是它的公开目录检索前端，**只做公版书**。
- 这与以分发受版权保护新书为卖点的「影子书库」是两回事：本库的盘点文档（docs/SURVEY2.md 第五节）已把盗版书库分发列为合规排除项，本模板不提供任何上传自有书籍、代找盗版资源的功能。
- 注意公版的地域性：一本书在美国进入公版，不等于在所有法域都进入公版；部署者面向特定地区运营时请自行核查当地版权期限。
