# 签到积分 / 抽奖 Bot

每日签到攒积分（连签加成）+ 积分榜 + 管理员发起按钮报名抽奖，群活跃玩法二合一。

## 部署要点
同单体三步部署，变量：BOT_TOKEN*、ADMIN_ID*、WEBHOOK_SECRET、LOTTERY_COST（参与抽奖门票积分，默认 0）、TZ_OFFSET（签到时区偏移，默认 8=北京）＋ 必须绑定 KV 变量名 BOT_KV。

## 玩法说明
- 用户：/qd 签到（基础 10 分，连签每天 +1 分，上限 +10）、/me 查积分、/top 榜单。
- 管理员在群里发 /lottery 奖品名 发起，成员点按钮报名（设了门票会先查积分够不够），/draw 抽奖ID [人数] 开奖，Bot 公布结果并私聊通知中奖者。
- 抽奖随机用 crypto 安全随机数；一场抽奖一条 KV 记录（lot: 前缀），开过奖的不能重复开。
- 排行榜一次最多扫 1000 个积分档案，小群够用；超大群请注意 KV 读次数。
