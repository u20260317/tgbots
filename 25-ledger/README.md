# 记账 Bot

一句话记一笔账：群里用是全群共享账本（AA、活动经费），私聊用是个人账本，按月自动汇总。

## 部署要点
同单体三步部署，变量：BOT_TOKEN*、WEBHOOK_SECRET、TZ_OFFSET（按哪个时区切月份，默认 8=北京）＋ 必须绑定 KV 变量名 BOT_KV。

## 用法
- 记账 -25 午餐 —— 支出（金额不写符号也算支出）
- 记账 +8000 工资 —— 收入（/jz 可代替「记账」二字）
- /账单 —— 本月明细 + 收入/支出/结余汇总；/账单 2026-10 查指定月
- /删账 编号 —— 删本月的一条（编号见 /账单，只能删当月，跨月请改 KV）

## 说明
- 账本按会话 ID 隔离：同一个群一份账，不同群互不可见；记录人会标注在每条账目后。
- 数据就是 KV 里一个 JSON 数组（键 ledger:<会话ID>:<月份>），量大（单月上千条）会变慢，小社群和个人使用没问题。
- 金额支持小数，汇总按两位小数显示。
