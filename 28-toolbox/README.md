# 工具箱 Bot

日常小工具集合：二维码、短链、哈希、Base64、UUID、随机选、时间戳互转。用完即走，无需 KV。

## 部署要点
同单体三步部署，变量只有 BOT_TOKEN* 和 WEBHOOK_SECRET。

## 命令
- /qr 文本 —— 生成二维码图片（api.qrserver.com 免费接口，图片以 URL 方式发送）
- /short https://… —— 短链接（is.gd 免费接口）
- /hash 文本 —— MD5 / SHA1 / SHA256 一次出全（MD5 是内置纯 JS 实现，已按标准测试向量校验；SHA 走 WebCrypto）
- /b64e 文本 / /b64d 编码 —— Base64 编解码，UTF-8 安全，中文不乱码
- /uuid —— 生成 UUID；/pick 苹果,香蕉,橙子 —— 随机选一个（crypto 安全随机）
- /ts —— 当前时间戳；/ts 1730000000 —— 时间戳转日期；/ts 2026-11-20 —— 日期转时间戳（日期按 UTC 解析）

## 说明
二维码和短链依赖两个免费公共接口，挂了会明确报错；其余工具全部本地计算，不联网。
