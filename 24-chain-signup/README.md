# 接龙报名 Bot

群活动报名接龙：点按钮名字按顺序进名单，再点取消，发起人截止定版。

## 部署要点
同单体三步部署，变量：BOT_TOKEN*、WEBHOOK_SECRET、ADMIN_ID、MAX_ENTRIES（默认 200）＋ 必须绑定 KV 变量名 BOT_KV。

## 用法
- 群里 /jielong 周六羽毛球局 建接龙（主题任意）
- 成员点「✋ 我接龙」报名，名单实时刷新（消息里展示前 50 名，总数另计）
- /closechain 接龙ID 截止并公布最终名单（发起人、群管理员或 Bot 管理员可操作）

## 说明
名单存在 KV 一条记录里，消息只是它的展示；就算消息被刷上去，用 ID 还能随时截止公布。
