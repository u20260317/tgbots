# 预约 / 订位 Bot

小商家的预约本：用户三步按钮（选服务→选日期→选时段）下单，时段占用表防撞，管理员一键确认/拒绝，开始前 1 小时自动提醒。对应 GuestKeepr / RentABot 那类预约产品的单文件版。

## 部署要点
同单体三步部署，变量：BOT_TOKEN*、ADMIN_ID*（收预约通知，没配就没人确认单）、WEBHOOK_SECRET、TZ_OFFSET（默认 8=北京）＋ 必须绑定 KV 变量名 BOT_KV。
⚠️ 到点提醒需要 Cron Trigger `*/10 * * * *`；不加 Cron 只是没提醒，预约流程照常。

## 玩法说明
- 服务与时段在代码顶部 CONFIG 改：SERVICES（服务名/时长）、WORK_START/WORK_END、SLOT_MINUTES（时段粒度）、DAYS_AHEAD（可约天数，默认 7）、CLOSED_WDAYS（每周休息日，0=周日）。
- 用户 /book：按钮三级选完出确认卡，点确认才真正占时段（占用前会再查一次表防抢）；/mybooks 看自己的单并可取消（取消立即释放时段）。
- 管理员：每张新单都会私聊推送，带 ✅确认 / ❌拒绝 按钮；拒绝自动释放时段并通知用户；/bookings 看今日全部预约。
- 提醒：Cron 每轮扫已确认未提醒的单，距开始 ≤65 分钟就推送（配 */10 Cron 最坏迟 10 分钟）。

## 注意事项
- 时段占用是「一个服务一个时段一张单」的模型：同一时段能并行接多单的店（如多位师傅），把服务按师傅拆成「剪发·阿May」「剪发·阿强」即可绕开，不用改代码。
- KV 无事务：两人同一毫秒抢同一时段，靠落单前复检 + 管理员确认兜底，极小概率撞单时管理员拒绝其一即可。
- 预约单与占用表都在 KV（book:r: / book:<日期>:<服务>），历史单不自动清理；量大时给 book:r: 加 expirationTtl 或定期手动清。
