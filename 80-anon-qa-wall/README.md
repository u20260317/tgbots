# 匿名提问墙 Bot

粉丝匿名提问 → 问题以卡片形式公开挂到频道墙上 → 博主公开作答。对标 NGL 式公开问答（@AskAnonFriendBot 一类）。

## 与 29 匿名信箱的区别（先看这段，别选错）
- **29 匿名信箱**：私聊双向——留言只有博主和留言者两人可见，博主私下回复，适合树洞/悄悄话。
- **80 提问墙（本模板）**：公开问答——问题和回答都发在频道里给所有人看，卖点是围观、互动与内容沉淀，适合 AMA/答疑型频道。
- 两者都匿名：提问者身份只存在 Bot 的 KV 映射里，频道侧（问题卡/答案卡）从头到尾不出现名字与 ID。

## 部署要点
单体三步部署，变量：BOT_TOKEN*、WALL_CHANNEL_ID*（目标频道，@用户名或 -100 数字 id，**Bot 必须先被拉进频道并设为管理员**，只需发帖权限）、WALL_REVIEW（=1 先审后发）、WALL_NOTIFY（=0 关回答私信通知）、ADMIN_ID（审核人+作答人）、WEBHOOK_SECRET ＋ 必须绑定 KV 变量名 BOT_KV。无需 Cron。

## 玩法说明
- /ask <问题>：编号从 `ask:seq` 自增，记录存 `ask:<号>`（{uid, q, status}，uid 只存映射、永不展示）。
  - 直接发模式（默认）：立刻以「❓ 匿名提问 #号」卡上墙，status=published。
  - 先审后发（WALL_REVIEW=1）：审核卡推给管理员（只看内容，卡上同样不带提问者身份），按钮 `ask:ok:<号>` 上墙 / `ask:no:<号>` 拒绝并私信告知提问者。
- /answer <号> <回答>（仅管理员）：答案卡「💬 回答 #号」发频道（带原问题引用方便围观者对上下文），随后私信通知提问者（WALL_NOTIFY 可关）。
- /myasks：按 uid 反查自己的提问与状态（review/published/answered/rejected）。

## 运营提示
- 公开墙比私信箱更容易被灌水与引战：新频道建议开 WALL_REVIEW=1 跑一阵再考虑直发。
- Bot 被移出频道管理员后发帖会失败，用户侧会收到如实报错而不是「已发布」的假成功。
