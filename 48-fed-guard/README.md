# 联邦群管 Bot

管「一群群」的群管进阶：联邦共享封禁、CAS 垃圾库预警、群笔记、关键词过滤器。模块 33 的成品落地版。

## 与 04 的分工（先说清）
- **04 群管理**：单群自治——入群验证码、欢迎、违禁词、防链接、单群 ban/mute。
- **48 联邦群管**：跨群能力——一份封禁名单全联邦共享、进群查全局垃圾库、群笔记与过滤器这类「群的记忆」。
两者可以在同一个群共存：04 的验证流程照常走，48 的联邦/CAS 检查在入群事件里先行。

## 部署要点
同单体三步部署，变量：BOT_TOKEN*、ADMIN_ID*（Bot 管理员，解封权）、WEBHOOK_SECRET、CAS_MODE（warn 默认 / kick）＋ 必须绑定 KV 变量名 BOT_KV。**BotFather 用 /setprivacy 关掉隐私模式**，否则收不到群内普通消息，笔记和过滤器都不触发；Bot 在每个成员群都要是管理员。

## 玩法说明
- /fedjoin（群管理员）：本群加入联邦；/fedleave 退出（退出后本群不再执行联邦封禁）。
- /fban：回复某人消息或带用户 ID 发起全网封禁，记录操作者与理由，并当场在本群 ban；名单里的人进任何成员群都会被直接移出。
- /fcheck 查名单（含封禁理由/操作者/来源群）；/unfban 解封**只认 Bot 管理员名单**（COMMANDS_ADMIN 分级菜单里也只有管理员看得见）。
- 新人进成员群：先查联邦名单（命中移出），再查 CAS 全局垃圾库（命中按 CAS_MODE 警告或移出）。
- /note 标签 内容（或回复消息 /note 标签）存群笔记，任何人发 #标签 触发；/notes 看清单。
- /filter 关键词 回复内容 加自动回复（命中回复原消息），/filters 看清单。

## 注意事项
- 联邦封禁是连坐工具：/fban 必须记操作者和理由（代码已存），并给被封者留申诉→管理员解封的路径，别做成一言堂按钮。
- CAS 是第三方社区数据，命中≠实锤：默认 warn 模式先跑一周看误报率，重要群尤其别一上来就 kick。
- 笔记/过滤器只有群管理员能写、所有人能触发，写入口的权限校验已逐个加好，改代码时别漏。
- 联邦成员名单存在 `fban:chats`（fban: 命名空间内的一个名单键），封禁记录是 `fban:<用户ID>`，两者同前缀不同形状，查注册表时注意区分。
