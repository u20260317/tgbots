# 频道导航 / 互推 Bot

频道目录站：频道主自助提交、管理员审核收录、用户按分类逛/搜/随机发现。互推曝光的合规玩法。

## 部署要点
同单体三步部署，变量：BOT_TOKEN*、ADMIN_ID*、WEBHOOK_SECRET ＋ 必须绑定 KV 变量名 BOT_KV。分类改 worker.js 顶部 CATEGORIES。

## 说明
- 只收有公开用户名的频道/超级群：提交时 Bot 会用 getChat 实查存在性并抓成员数快照，假频道进不来；成员数只是收录时快照，条目里已标注，不会实时刷新。
- 提交格式：/submit @频道 | 分类 | 一句简介（竖线分隔），分类必须在 CATEGORIES 里。
- 浏览按成员数排序展示前 10；重复提交会被拦（已收录或审核中）。
