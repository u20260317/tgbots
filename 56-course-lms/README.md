# 课程 / LMS Bot

把课卖进 Telegram：管理员在 Bot 里直接建课、逐课加内容和测验，学员按顺序学、答对解锁下一课，付费课人工确认收款后解锁。对应 coob.app 那类 Telegram 课程平台的单文件版。

## 部署要点
同单体三步部署，变量：BOT_TOKEN*、WEBHOOK_SECRET、ADMIN_ID*（建课与确认收款，没配就没人能建课）、PAY_INFO（收款说明，展示给学员）＋ 必须绑定 KV 变量名 BOT_KV。不需要 Cron。

## 玩法说明
管理员（私聊）：
- /addcourse → 按提示发标题 → 发价格（0=免费，数字=付费价）→ 回课程 ID；
- /addlesson <课程ID> → 发课时标题 → 发正文 → 测验二选一：发「跳过」，或按 `问题|选项1|选项2|选项3|正确序号` 发一道按钮题；
- /delcourse <课程ID> 删课；收款确认走消息里的 ✅/❌ 按钮，不用敲命令。
学员：
- /courses 课程列表（按钮进课）；付费课先看到收款说明，点「我已付款」后等管理员确认，确认后自动通知并解锁；
- 学习是一课一屏：正文 + 测验按钮（答错可重答，不锁死）或「学完，下一课」按钮，进度随时存 learn:<uid>:<课程ID>；
- /myprogress 看每门课学到第几课/是否结课。

## 注意事项
- 课时正文是纯文本（单条上限约 3800 字，Bot 消息本身上限 4096）：长课请拆成多个课时；要发图文/视频课时，把素材发到频道后在正文里贴链接，或按模块 08 的 file_id 思路自行扩字段。
- 付费确认是「人工核实真实到账再点通过」：Bot 不经手钱，PAY_INFO 里写清收款方式与备注要求（如备注 TG 用户名），防冒充点「我已付款」——确认权始终在管理员。
- 想用 Stars 官方支付：把 showPaywall 换成模块 24 的 sendInvoice + successful_payment 里置 paid=true 即可，其余流程不变。
- 课程与进度都在 KV 里，删课不删进度记录（/myprogress 会自动跳过已删课程）。
