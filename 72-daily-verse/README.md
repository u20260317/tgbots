# 每日经文 Bot

每天一句经文 + 礼拜时间查询：经文走本地公版译本种子库按日期轮换，礼拜时间走 Aladhan 免费 API，订阅后 Cron 每日推送。

## 部署要点
单体三步部署，变量：BOT_TOKEN*、PRAY_CITY / PRAY_COUNTRY（默认礼拜城市，英文名，可空）、ADMIN_ID（看 /vstats）、WEBHOOK_SECRET ＋ 必须绑定 KV 变量名 BOT_KV ＋ **必须加 Cron Trigger**（如 `0 0 * * *` UTC = 北京 8 点）才能每日推送；不配 Cron 时查询功能照常可用。

## 玩法说明
- /verse 今日经文：用「一年第几天 % 库长度」取句，全年轮换。/faith 按钮切换经文库（`bible` 圣经 / `quran` 古兰经），偏好存 `verse:pref:<uid>`。
- /pray 礼拜时间：城市来源优先级 = 命令参数 > /setcity 个人设置 > 环境默认；三处都没有时**不猜、不编**，回提示让用户先设置。时间由 Aladhan 按城市与计算法（method=2）给出。
- /subverse 订阅存 `verse:sub:<uid>`；Cron 扫订阅逐个推送，推送失败（拉黑等）自动退订。

## 内容与尊重性说明（重要）
- 种子库只收录**公有领域译本**的短句：圣经和合本（1919 年，已进入公版）、古兰经马坚译本（译者 1981 年逝世，按多数法域已进入公版）。部署前请按你所在法域再确认一次。
- 文本库就是 worker.js 顶部 `VERSES` 一个 CONFIG 对象：加经文、换译本、只保留单一信仰分库，直接改数组即可，不需要动任何逻辑代码。
- Bot 只做「原文推送 + 时间查询」，**不生成、不提供教义解读**；礼拜时间因教法学派与本地习惯可能有差异，回复里已注明以本地清真寺公告为准。
- 扩库建议：从权威公版来源逐条人工录入，不要用爬虫批量抓取受版权保护的现代译本。
