# AI 绘图 Bot

文字画图 + 按描述改图，带每日额度和一键重新生成。填补 31（只聊天）与 43（只 OCR/处理）的空白：这一号是真的「生成」图片。

## 部署要点
同单体三步部署，变量：BOT_TOKEN*、IMAGE_API_URL*（绘图 API base 地址，OpenAI images 兼容口径）、IMAGE_API_KEY*（Secret）、WEBHOOK_SECRET、IMAGE_MODEL（默认 dall-e-3）、IMAGE_SIZE（默认 1024x1024）、DAILY_LIMIT（默认 10 张/人/天）、TZ_OFFSET（切日时区，默认 8）＋ 必须绑定 KV 变量名 BOT_KV。不需要 Cron。
⚠️ 没配 IMAGE_API_URL/KEY 时，/draw 只会明确回复「未配置」，不会假装生成成功——先配好再对外开放。

## 玩法说明
- /draw <描述>：文生图，出图后附「🔄 重新生成」按钮（提示词存 aimg:p: 一周，按钮只认图主本人）。
- /edit <描述>：回复一张图（或图片与命令发在一起）按描述改图，走 images/edits 口径。
- /quota：看今日已用/剩余张数；生成失败不扣额度，成功才扣。
- API 返回 url 就直发 sendPhoto，返回 b64_json 就解码成字节上传，两种都兼容。

## 换源说明（只改一个函数）
绘图调用全在 genImage / editImage 两个适配函数里，默认 OpenAI images 兼容口径。要接 Kandinsky、SYNTX AI 或其他聚合口径，只改这两个函数的请求地址、参数与返回解析，下面的限额/发送/重画流程不用动。各家对 edits 改图的支持不一：不支持的源会把官方错误原样回给用户，并提示改用 /draw。

## 注意事项
- 额度是「防刷」而非计费级精确：KV 最终一致，极端并发下可能多画一两张，可接受；真要计费请在 API 侧设硬限额。
- 绘图 API 的内容政策由上游执行，被上游拒绝时错误会原样透传给用户。
- 单张图生成耗时受上游影响（常见 5–30 秒），webhook 里已先回「正在生成」再出图，不会让用户干等无反馈。
