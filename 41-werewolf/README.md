# 狼人杀主持人 Bot

Bot 当法官在群里主持狼人杀：群里报名发牌、夜晚各角色私聊行动、天亮结算、白天公投，全程一份 KV 对局状态推进。模块 35 的成品落地版。

## 部署要点
同单体三步部署，变量：BOT_TOKEN*、WEBHOOK_SECRET ＋ 必须绑定 KV 变量名 BOT_KV。不需要 Cron（阶段靠玩家行动推进，卡住由房主强制推进）。Webhook 的 allowed_updates 已含 callback_query（/setWebhook 时自动带上）。

## 玩法说明
- 群里发 /werewolf 开房（发的人是房主，自动入座），其他人点「✋ 我要参加」报名，满 4 人房主点「开始游戏」。
- 身份配置：狼数 = max(1, 人数/3 向下取整)，预言家、女巫各 1，其余平民。身份牌只私发到每位玩家的私聊。
- 夜晚：狼人在私聊点按钮选刀口（队里最先提交的一刀锁定）；预言家选查验对象，结果只回给他；狼人首刀落定后女巫才会收到提示，看着刀口选救/毒/不用药。三方都行动完自动天亮。
- 白天：群里出公投键盘，一人一票可改票，全员投完自动放逐最高票，或房主点结算。
- 胜负：狼全灭好人胜，狼数 ≥ 好人数狼胜；结束公布全部身份。
- /myrole 私聊查自己当前身份；夜晚卡住时房主可点「强制推进」（未行动者视为放弃）。

## 本局规则（写死在代码里，改规则改 maybeDawn）
- 女巫解药只能救狼人的刀口，毒药无视解药（同人同夜又被刀又被毒，救了也死）；解药、毒药整局各一瓶。
- 狼人多只时以最先提交的刀口为准，不做狼队内投票。

## 注意事项
- ⚠️ 头号翻车点：玩家没私聊启动过 Bot 就收不到身份牌，开局私发失败会被自动剔除（群里只报人数，绝不公布其身份兜底）。开局前先让大家私聊发一次 /start。
- 对局状态 wolf:<群ID> 一条记录整局覆写，KV 最终一致对这种低频行动无感；一个群同时只能有一局。
- 平票时按先达到最高票者放逐（Object 顺序），想改成平票无人出局改 tallyVotes 即可。
