# 投票问卷 Bot

一行命令发起按钮投票：可改票、可匿名、发起人截止公布。自研投票的好处是数据在自己 KV 里，不像原生 Poll 那样发出去就管不了。

## 部署要点
同单体三步部署，变量：BOT_TOKEN*、WEBHOOK_SECRET、ADMIN_ID ＋ 必须绑定 KV 变量名 BOT_KV。

## 用法
- /poll 问题|选项1|选项2（2~10 个选项，竖线分隔）
- /poll anon 问题|选项1|选项2 匿名版（不显示谁投了谁）
- /closepoll 投票ID 截止（发起人或管理员），Bot 公布最高票

## 说明
- 票数和百分比实时刷在投票消息上，非匿名版附最近 15 条投票明细。
- 一人一票靠 KV 里 votes 的用户 ID 键去重，改票直接覆盖，不会重复计。
