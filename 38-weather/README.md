# 天气 Bot

查天气 + 每日预报订阅，数据源 Open-Meteo（免费、无需 Key、无调用注册）。

## 部署要点
同单体三步部署，变量：BOT_TOKEN*、WEBHOOK_SECRET ＋ 绑定 KV 变量名 BOT_KV（存订阅；不绑 KV 也能用 /tq 查询，订阅命令会提示）。
每日推送需给 Worker 加 Cron Trigger，推荐 `0 23 * * *`（UTC 23:00 = 北京 7:00）：每次 scheduled 触发就给全部订阅者推当天预报。

## 玩法说明
- /tq 北京（或私聊直接发城市名）→ 当前天气（温度/体感/湿度/风速）+ 未来 3 天（天气/高低温/降水概率）。
- /sub 北京 订阅每日预报（一人一城，重复 /sub 直接换订）；/mysub 看订阅；/unsub 退订。
- 城市名走 Open-Meteo 地理编码（支持中文名，取第一个匹配，显示「城市 · 省 · 国家」防同名误认）；预报按当地时区取。
- 推送时被用户拉黑（403）的订阅自动清除，不反复白跑。

## 注意事项
- 天气代码用 WMO 标准码映射中文（worker.js 里的 WMO 表），个别罕见码显示原文代码。
- Open-Meteo 免费版有合理使用限制，海量订阅者请自行评估或换付费数据源（改 forecast/geocode 两个函数即可）。
- 这是模块 19（外部 API 调用与提醒）的一个落地样例：换数据源/换查询类型照此结构改。
