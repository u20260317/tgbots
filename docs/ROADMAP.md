## 未来候选（⚠️ 只是候选，未立项、未排期）

以下条目是「想过、记下来」的方向，**没有一项在开发中**。用户点单后才会按老规矩立项（单文件 + docs + 实测）。

| 候选 | 内容 | 触发条件 |
|---|---|---|
| D1 迁移指南 | 一篇文档讲清何时该从 KV 迁 D1（强一致、关系查询、list 扫描变重时），可能附个别重状态模板的 D1 变体 | 某个模板的 KV 用法先撞上一致性/查询瓶颈 |
| Bot API 新能力观察 | 持续盯官方 API 演进（评估框架见知识库 02）：新消息类型、新支付能力、新托管能力出现时先评估适配成本，再决定是否入库；Managed Bots 已在 54 落地，是这条线的第一个成果 | 官方发布值得跟的新能力 |
| 组合模板扩充 | combos/ 目前只有 3 个；[COOKBOOK.md](COOKBOOK.md) 的 10 个配方是现成候选，可逐个拼成正式组合目录（拼装 + 实测 + 回填 TESTING） | 用户点名某个配方 |
| 演示与脚手架 | 模板演示截图/GIF、一键生成新模板骨架的脚手架脚本、CI 自动语法检查 | 仓库维护成本值得投入时 |

## 明确不做（合规排除，不是「还没做」）

批量私信群发、采集群成员、自动拉人/邀请农场、MTProto 绕 Bot API 限制、绕验证码/风控、真钱赌博、盗版资源分发、绕 DRM/付费墙、DEX 代签名托管私钥。完整清单与理由见 [SURVEY.md](SURVEY.md) 与 [SURVEY2.md](SURVEY2.md) 的排除节——这些不会因为出现在路线图里而被重新考虑。
