# 18 · Workers 免费额度工程

## 本篇讲什么

在 Cloudflare Workers 免费计划里把 Bot 养活、养久的工程方法：免费额度到底卡在哪几个维度、哪些设计最烧额度、省流的固定套路有哪些。本库全部模板都按「免费计划可长期运行」设计，这一篇是那套设计哲学的说明书。

## 核心概念

### 免费额度的四个维度（量级，以 Cloudflare 官方文档为准）

- **请求数**：Workers 免费计划每天有请求量上限（十万量级），webhook 每来一条更新就是一次请求——用户量决定消耗，没人聊天就不耗。
- **CPU 时间**：单次请求的 CPU 时间很短（免费版毫秒级），注意是 CPU 时间不是墙钟时间：等 fetch 不烧 CPU，但本地大循环、重解析、加解密烧。
- **子请求数**：单次执行能发出的 fetch 次数有上限（免费版约 50 量级）——一次请求里又查 KV 又调十几个外部 API 的设计会先撞这里。
- **KV 读写**：读便宜写贵，免费版每日写操作约千次量级、读约十万量级。**写额度是全库最稀缺的资源**，多数省流设计都是在省 KV 写。
- **Cron**：触发器个数与最小间隔有限制，免费账号的 Cron 数量不多，别一个功能占一个触发器。

（以上数字会随官方政策调整，动手前查 Cloudflare 文档；工程姿势是把消耗做成可估算、可调节，而不是背数字。）

### 谁在烧额度：Bot 的典型消耗画像

- **群消息计数类**：群里每条消息都触发 webhook + 写一次 KV，是双料消耗冠军（隐私模式与 allowed_updates 裁剪是第一道闸，见 03 篇）。
- **高频轮询类**：RSS、价格、开播状态——Cron 间隔每缩短一倍，日消耗翻一倍。
- **广播类**：一次群发 = N 次子请求 + 进度写回，分片与节流决定它是任务还是事故（见 08 篇）。
- **多步向导类**：每步一次请求 + 一次 KV 写，用户量大时 FSM 状态写不容忽视（但步数有限，属于可控消耗）。

## 省流设计模式（本库的固定套路）

1. **拉长 Cron 间隔，按业务时效定档**：行情分钟级、RSS 与监控小时级、日报天级。天级任务用每天一次的 Cron，间隔里再用 KV 存的上次运行时间做「软件分频」——多个低频任务共用一个高频 Cron 入口，各自判断到没到自己的点儿。
2. **首次只播种**：订阅类轮询第一次跑只记录当前状态（最新一条 RSS、当前提案列表、当前价格），不推送——否则新部署瞬间把历史存量全推一遍，既刷屏又烧额度。本库 11/65/74 都是这个口径。
3. **变化才动作**：轮询先比 hash/状态指纹，没变就只写一次极小的检查点（或不写），变了才走完整处理与推送。60 号的快照哈希比对是范本。
4. **写聚合**：计数按天/按批攒成一键一次写（22 号群统计、各类 cnt: 日计数），拒绝「一事件一写」。
5. **手动刷新节流**：给用户点的「立即刷新」类入口加冷却（KV 存上次时间，冷却内直接回缓存结果），防连点把外部 API 与子请求烧穿。
6. **读缓存**：配置、目录这类读多写少的数据，在单次请求内读一次内存复用；跨请求可接受旧数据时用边缘缓存兜一层（公开 GET 接口尤其值得）。
7. **外部调用先行止损**：调外部 API 前先做本地校验（订阅是否存在、额度是否用完、是否在冷却），不满足就不发请求——59 号总结器「先判未配 LLM 再抓取」就是把顺序倒过来省请求。

## 实操要点

1. 上线前算三笔账：日请求量（日活 × 人均触发）、单请求子请求峰值、KV 日写入量。对照免费额度留一半余量再上线。
2. 给每个 Cron 任务标注「间隔 × 单轮子请求数」，乘起来就是它的日成本；新加轮询先过这道算术。
3. 额度告警靠观测：把 429、KV 写失败、子请求超限的报错单独记一类日志（见 11 篇三个数），别等用户投诉才发现额度烧穿。
4. 真撞顶了先优化再考虑付费：多数 Bot 的消耗大头是设计浪费（过密轮询、重复写），改设计比升级计划便宜一个数量级。

## 常见坑

- **Cron 写成每分钟扫全表**：监控类模板最爱犯——每分钟 list 全量键 + 逐个 fetch 外部源，一天下来子请求与 KV 读双爆。按到期时间建索引、只扫到点的。
- **每次请求都 setMyCommands/重复注册**：注册类调用只在部署时做，别混进业务请求。
- **把图片/文件过自己的 Worker 中转**：能用 file_id 和 URL 直传的别下载再上传（见 04 篇），带宽与 CPU 都在你账上。
- **测试期把额度烧光**：全量回放测试本身也耗请求与 KV 写，测试用独立命名空间并控制轮次（见 16 篇），别拿生产额度练手。
