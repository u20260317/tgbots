# 竞答游戏 Bot

群里抢答竞猜：Bot 逐题出题，第一个答对的人得分，全场结束公布排名，分数累计进赛季总榜。

## 部署要点
同单体三步部署，变量：BOT_TOKEN*、WEBHOOK_SECRET、ADMIN_ID（可强制结束任何一场）＋ 必须绑定 KV 变量名 BOT_KV。

## 玩法
- /quiz 开局（共 CONFIG 题库那么多题，每题 +10 分）
- 点选项按钮抢答；答错的选项会被记下，同一个人不能靠穷举蒙对
- 全部答完自动结算；/stopquiz 由开局人或管理员提前结束结算
- /quiztop 赛季总榜 Top 10（跨场累计）

## 换题库
改 worker.js 顶部 QUESTIONS 数组：{ q: "题面", options: ["选项"…], answer: 正确选项下标（从 0 数） }。内置 8 道示例题，正式用请换成你自己的。
