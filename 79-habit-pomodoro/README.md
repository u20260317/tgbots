# 习惯打卡 / 番茄钟 Bot

个人习惯实体（连续天数 streak + 近 7 天周视图）与 Cron 驱动的番茄钟，两件小事一个 Bot。13 号是群积分签到、36 号是提醒待办，这个补的是「习惯」本身。

## 部署要点
单体三步部署，变量：BOT_TOKEN*、ADMIN_ID（看 /habitstats）、WEBHOOK_SECRET ＋ 必须绑定 KV 变量名 BOT_KV。用番茄钟**必须加 Cron Trigger `* * * * *`（每分钟）**，精度就是 Cron 的粒度；只用打卡可以不配 Cron。

## 玩法说明
- 习惯存一人一键 `habit:<uid>` 整表：{name, checks:{日期:1}, streak, best}。打卡按钮回调 `habit:do:<下标>`——用数组下标而不是习惯名进 callback_data，名字含中文/冒号都不怕超长与解析歧义。
- 日期键沿用 13 号口径：UTC+8 切日。streak 算法：今天已打卡从今天数、没打从昨天数（今天没打不算断签），打卡时刷新 streak 与历史最佳 best。周视图近 7 天 ✅/· 一行看完。
- 番茄一颗一键 `pomo:<uid>:<随机ID>`：{end 毫秒戳, label, chat}，Cron 每分钟扫 `pomo:` 前缀，到期推送「🍅 番茄完成」并删键；键带 expirationTtl 兜底防僵尸。/pomos 可取消（回调校验归属，只能取消自己的）。

## 边界
- 免费版 Cron 最细 1 分钟，番茄提醒误差 ≤1 分钟，这是平台粒度不是 bug，README 与 /pomo 回复都不承诺秒级。
- 习惯上限 20 个/人、整表读写——个人低频场景够用；要做群共学排行可拼 13 的积分与排行榜模块。
