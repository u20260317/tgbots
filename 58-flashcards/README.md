# 闪卡记忆 Bot

Anki 式间隔重复：建卡、到期复习、三档自评，SM-2 简化算法自动排下次复习时间。对应 PocketAnki / MemoCard 那类产品，零外部 API，是全库对 Workers 适配度最高的一类。

## 部署要点
同单体三步部署，变量：BOT_TOKEN*、WEBHOOK_SECRET ＋ 必须绑定 KV 变量名 BOT_KV。
每日到期提醒需 Cron Trigger，例如 `0 1 * * *`（UTC 01:00 = 北京 09:00）；不加 Cron 只是没每日推送，/review 照常能用。

## 玩法说明
- /add 正面|背面 建卡（竖线分隔，中英文竖线都认），新卡立即到期可复习；
- /review：一屏一卡——先示正面，点「👀 看背面」翻面，再点 😵忘了 / 🤔模糊 / 😎记得 自评，评完自动出下一张到期卡；
- 调度规则（代码注释里有完整说明）：忘了→10 分钟后重来并降难度系数；模糊→间隔小步增长；记得→1 天、3 天、之后按系数放大；
- /cards 牌组列表（带删除按钮）；/stats 看总数/已掌握（间隔≥21 天）/到期数/累计遗忘；
- 每天 Cron 按 card:users 名单逐个点数，只提醒「有卡到期」的人。

## 注意事项
- 自评要诚实：点「记得」实际没记住，算法会把间隔拉得很长，等于给自己挖坑——这是所有间隔重复工具的共同前提。
- 牌组按用户隔离（card:<uid>:<卡ID>），群里也能建卡复习，但内容会发在群里，私密内容请私聊用。
- 单人牌组按 KV list 上限设计为千张级；上万张请换 D1 或分页扫描。
- 想升级到 FSRS 算法：只改 gradeCard 一个函数，数据字段（ease/interval/reps/due）不用动结构、加两个字段即可。
