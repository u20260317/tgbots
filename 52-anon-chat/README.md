# 匿名随机聊天 Bot

> ## ⚠️ 安全配套说明（部署前必读）
> 陌生人匿名社交是高风险品类，本模板把安全措施做进了本体，**不要删改后上线**：
> - **入场门槛**：首次使用强制展示规则 + 未成年提示，用户点「我已成年并同意规则」后才能进匹配队列；
> - **举报闭环**：每条转发消息都带控制条（举报/下一位/断开），举报走两步确认防误触，累计达阈值（默认 3 次，可用 BAN_LIMIT 改）自动封禁并通知管理员；
> - **内容拦截**：敏感词过滤（代码顶部 CONFIG.BAD_WORDS 自行维护），管理员可开「禁媒体模式」只许文字，从源头掐掉图片骚扰；
> - **匿名实现**：消息用 copyMessage 转发，对方看不到你的账号与 ID；但请注意，Bot 运营者（你）在 KV 里能看到配对关系，部署时应在规则里如实说明。
> 运营者仍需对自己司法辖区的合规要求（未成年人保护、内容治理）负责，本模板不构成法律意见。

陌生人一对一随机配对：/match 进队列，配对后直接发消息互聊，/next 换人、/stop 断开。与 29（匿名信箱：给指定的人留匿名话）不同，这里是随机陌生人。

## 部署要点
同单体三步部署，变量：BOT_TOKEN*、WEBHOOK_SECRET、ADMIN_ID（收举报通知+管理命令，建议必填）、BAN_LIMIT（默认 3）、NO_MEDIA（填 1 默认禁媒体）＋ 必须绑定 KV 变量名 BOT_KV。不需要 Cron。

## 玩法说明
- 用户侧：/start 看规则 → 点确认 → /match 匹配 → 直接发消息聊天；每条收到的消息下方有 ⏭下一位 / ✖️断开 / 🚨举报 按钮，也可用 /next、/stop 命令。
- 举报：点举报 → 确认 → 双方断开，举报计数 +1 并通知管理员；达阈值自动写 ban: 封禁。
- 管理员：/achstats 看队列与封禁数；/unban <用户ID> 解封并清零计数；/media on|off 切换禁媒体模式（存 KV，优先于 env 默认值）。
- 配对关系存 ach:pair:<uid> 双向键，队列存 ach:queue 数组。

## 注意事项
- KV 无事务：极端并发下队列可能出现重复/漏配，后果仅限多一条提示或一局错配，自用/小流量可接受；要做大请把队列换成 Durable Objects。
- copyMessage 失败（如对方拉黑 Bot）会自动清配对并提示，不会让用户对着空气说话。
- 敏感词是字面包含匹配，只能挡直白违规，挡不住变体与图片内容——禁媒体模式 + 举报闭环才是主力防线。
- 只处理私聊，群里发命令不响应。
