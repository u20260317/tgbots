# 任务赚钱 Bot

管理员发任务、用户做任务攒积分、积分兑换走管理员审核发放的任务平台。

## 部署要点
同单体三步部署，变量：BOT_TOKEN*、ADMIN_ID*、WEBHOOK_SECRET、EXCHANGE_RATE（兑换说明文案）＋ 必须绑定 KV 变量名 BOT_KV。Bot 必须是 join 类任务目标频道的管理员（否则自动验证查不到人）。

## 管理员速查
- /addtask join @频道 积分 标题 —— 加入类，自动验证
- /addtask manual 链接或说明 积分 标题 —— 手动类，用户提交后你按钮审核
- /deltask 任务ID 下架

## 说明
- join 类验证用 getChatMember，用户退订后已领的积分不追回（防退订刷分要靠任务设计：比如奖励延迟发放，本模板是即时发放，先说清）。
- manual 类和兑换都走管理员按钮审核，积分扣账发生在兑换通过那刻，未通过不扣。
- 积分只是 Bot 内的账，价值和发放由你负责；任务目标请只放你自己或已授权的频道/内容。
