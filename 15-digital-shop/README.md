# 数字商品自动售货 Bot

卡密/链接/账号类数字商品自动发货：上架 → 导入库存 → 用户下单付款 → 管理员确认 → Bot 自动弹出一条库存私聊发货。

## 部署要点
同单体三步部署，变量：BOT_TOKEN*、ADMIN_ID*、PAYMENT_INFO*、WEBHOOK_SECRET、SHOP_NAME ＋ 必须绑定 KV 变量名 BOT_KV。

## 管理员速查（私聊 Bot 发命令）
- /addproduct 商品名|价格文案 建商品（记下返回的商品 ID）
- /addstock 商品ID 卡密内容 一次加一条库存，多发几次补满
- /stock 商品ID 查库存数；/delproduct 商品ID 下架；/orders 看订单总数（明细在 KV）

## 说明
- 同 14，是人工收款确认模式：管理员点确认那刻才扣库存发货；库存不足时确认会被拦截并提示先补货或拒绝退款，不会误发。
- 发货内容会被原样私聊给买家，且订单记录里留一份（KV 的 order: 键含 delivered 字段），方便售后对账。
- 库存就是明文存在 KV 里，别卖你输不起的东西；贵重商品建议拆小批次上架。
