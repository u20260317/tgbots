# 商城 Bot（加盟连锁 · 母体 × 商店）

> ## ⚠️⚠️⚠️ 风险提示（部署前必读）⚠️⚠️⚠️
> 本 Bot 是连锁商城母体：**店主把自己 Bot 的 Token 交进来开店**，代管风险与母体 Bot 完全相同：
> - 店主 Token 一律 **AES-GCM 加密**后才存 KV，密钥 `TOKEN_ENC_KEY` 只放 Secret；任何界面/日志**不回显 Token 原文**；店主随时可去 @BotFather **/revoke** 退出托管；
> - 🔴 **资金红线：平台绝不代收代付。** 本模板用人工确认流——买家按店主说明直接转账给店主，钱不经平台手。总部收入只应走订阅费/批发差价等干净通道；
> - 🔴 **连带红线：连锁店卖违禁品/搞诈骗会牵连母体**（举报、封禁可能波及平台）。入驻文案已写明「经营责任归店主、平台有权停店」，总部要用好 /mstop 熔断，先停后查。

总部运营平台、加盟商 1 分钟开店：门面是店主自己的 Bot，总部统一提供系统、托管、升级与货源池。

## 部署要点
同单体三步部署，变量：BOT_TOKEN*（商城母体，Secret）、TOKEN_ENC_KEY*（Secret；32 字节随机数 base64，生成法见 32 号 README）、ADMIN_ID*（总部管理员）、WEBHOOK_SECRET、MALL_MARKUP（总部货源默认加价 %，默认 20）＋ 必须绑定 KV 变量名 BOT_KV。

## 玩法说明
- **总部**（母体私聊，管理员）：/hqadd 名称|批发价 上架货源、/hq 看货源池、/hqdel 下架；/stores 看全部店铺、/mstop <slug> 熔断/恢复。
- **开店向导**（私聊）：/open → 选模式（总部货源/混合/完全自营）→ 发店铺 Bot Token（验真）→ 起店名 → 确认开店。子 Bot 自动设 Webhook 并注册买家菜单。
- **店主**：/mystores 管理店铺（停店/恢复/关店）；在**自己的子 Bot 里**发 /start 能看到店主命令：/addprod 名称|价格 上架自营商品、/addstock 商品ID 卡密 补卡密库存、/delprod 下架、/orders 看待确认订单。
- **买家**（子 Bot 里）：/shop 目录（总部货源带加价展示 + 自营商品）→ 商品卡加购物车 → /cart 改数量 → 结账生成订单 → 按店主说明付款 → 店主在订单通知卡点「确认收款并发货」→ 有卡密库存的自营商品自动弹出私聊发货，其余由店主人工发货；总部货源的履约归总部（平台侧线下处理）。
- 店面价 = 批发价 ×(1+加价%) 向上取整；购物车/订单都在租户前缀 KV 内（cart:/order:），各店互不可见。

## 注意事项
- 与 32 母体同样的安全基线：slug 随机路径、每店独立 secret_token、Token 密文存储、删除托管时销毁密文并删子 Bot Webhook。
- 店主要先在自己的子 Bot 里发一次 /start，店主订单通知才发得出去（Telegram 不允许 Bot 主动私聊没启动过它的人）。
- v1 简化项（写明免得误会）：加价 % 全平台统一（MALL_MARKUP），未做单店自定义；未做 Stars 自动收款（可把模块 24 的到账发货换进 payok 的位置）；未做入驻审核队列，总部靠 /stores 巡查 + /mstop 熔断。
- 订单状态只有 waitconfirm/done/cancelled 三态；卡密只在「确认」时按数量弹出，取消订单不回滚已弹出的卡密（已弹即视为已交付，注意对账）。
