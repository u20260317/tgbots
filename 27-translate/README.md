# 翻译 Bot

私聊发文字自动互译，群里回复消息 /fy 翻译。无需 KV、无需任何 API Key。

## 部署要点
同单体三步部署，变量只有 BOT_TOKEN* 和 WEBHOOK_SECRET。

## 用法
- 私聊直接发文字：含中文 → 翻成英文；其它语言 → 翻成中文
- /fy en 你好世界 —— 指定目标语言（en/ja/ko/fr/de/es/ru 等标准代码）
- /fy 一段外文 —— 不带代码时按自动互译规则
- 群里：回复某条消息发 /fy —— 把那条翻成中文（/fy en 则翻成英文）；群里普通消息 Bot 不插话

## ⚠️ 接口说明（重要）
翻译走的是 Google 翻译的**非官方免费接口**（translate.googleapis.com 的 gtx 客户端口），优点是免 Key、质量就是 Google 翻译；缺点是它不是官方 API，随时可能限流、改格式或停用。失效时 Bot 会明确回复「接口暂时不可用」而不是乱翻。真失效了可替换「翻译引擎」模块里的 translate() 实现（比如换 DeepL/有道官方 API，需要自备 Key），业务主流程不用动。
